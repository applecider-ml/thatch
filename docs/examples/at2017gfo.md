# AT2017gfo (Kilonova)

AT2017gfo is the electromagnetic counterpart of GW170817, the first binary neutron star merger detected by LIGO/Virgo. It has 229 HST observations across 23 programs, including WFC3/IR grism spectroscopy.

## Photometry

THATCH extracts multi-band photometry from F110W, F160W, F153M, F606W, F475W, F275W, F225W, and F336W observations spanning days 5–1273 post-merger.

## Spectroscopy

- **STIS/G230L**: UV spectrum at +5.6 days
- **WFC3/IR G102+G141**: NIR grism spectra at +5, +7, +9, +10 days (extracted via grizli)

## Validation

Aperture photometry achieves 0.02 mag RMS agreement with published values (Cowperthwaite+2017, Lyman+2018).
